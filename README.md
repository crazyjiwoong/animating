# FrameFlow · 애니메이션 스튜디오

브라우저에서 바로 쓰는 프레임 애니메이션 제작 앱입니다. 클립 스튜디오처럼 **레이어 × 프레임** 구조로 작업하고,
그림을 붙여넣어 프레임마다 조금씩 옮기며 애니메이션을 만들 수 있어요. 음악을 넣으면 **프레임마다 어떤 음이 나오는지** 보여줍니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성
```

`main` 브랜치에 푸시하면 `.github/workflows/deploy.yml` 이 GitHub Pages 로 배포합니다
(저장소 Settings → Pages → Source 를 **GitHub Actions** 로 설정).

## 기능

| 영역 | 내용 |
| --- | --- |
| 홈 | 새로 만들기(크기·FPS·배경), 불러오기(`.ffanim` 파일), 최근 작품 목록(썸네일·이름 변경·삭제) |
| 프레임 속도 | 6/8/12/15/24/30/60fps 선택 시 그 속도로 재생되는 **예시 영상**과 설명 표시 |
| 이미지 | `Ctrl+V` 붙여넣기, 파일 가져오기, 드래그 앤 드롭 → 새 이미지 레이어 (비파괴 이동·크기·회전·반전). 선택한 이미지 레이어의 빈 프레임에 붙여넣으면 그 자리에 들어가고, 여러 장을 한 번에 가져오면 **한 레이어에 프레임 순서대로** 넣을 수 있음. 프레임별 이미지 교체 |
| 프레임 설정 | 프레임(썸네일/번호/셀)을 **두 번 누르면** 설정 창 → **같은 그림 N개 추가하기**, 빈 프레임 N개, 이동, 비우기, 삭제, 메모 |
| 그리기 | 브러시(필압·손떨림 보정), 지우개, 도형(직선·사각형·원, 채우기), 채우기(선화 기준), 스포이드, 이동·변형, 손 도구 |
| 그림 길이 (노출) | 타임라인에서 같은 그림이 이어지는 구간은 하나의 막대. **막대 끝을 끌어** 몇 프레임 동안 보일지 조절(뒤 그림 밀기/덮어쓰기). 우클릭: 끝까지 늘리기·길이 입력·1프레임으로·여기서 나누기. 늘린 구간은 함께 편집됨 |
| 이전 프레임 겹쳐 보기 | 현재 프레임 위에 이전(다음) 프레임을 반투명하게. 설정 → 보기에서 끄기·불투명도·장 수·원래 색/색 입히기·같은 그림 건너뛰기 |
| 보기 도구 | 격자, 안전 영역, 좌우 반전 보기, 재생 속도 0.25×~2× |
| 레이어 | 불투명도, 합성 모드 15종, 보이기/숨기기, 잠금, 투명 픽셀 잠금, 이름 변경, 드래그 순서 변경, 복제, 아래와 합치기, 래스터화 |
| 타임라인 | 레이어×프레임 그리드, 썸네일, 드래그로 프레임 순서 변경, 스크럽, 어니언 스킨(앞/뒤 장수·투명도), 반복 재생 |
| 음악 | 파형 표시, **프레임별 주요 음(도레미/CDE)·음량·박자** 분석, 시작 프레임·앞부분 자르기·볼륨, 스크럽 사운드, 음 미리듣기, 음악 길이만큼 프레임 늘리기 |
| 저장 | 브라우저(IndexedDB) 자동 저장(20초) + `Ctrl+S`, `.ffanim` 프로젝트 파일 내보내기/열기 |
| 내보내기 | MP4/WebM 동영상(음악 포함), GIF, 현재 프레임 PNG, PNG 묶음(zip), 스프라이트 시트 |
| 기타 | 실행 취소/다시 실행, 셀 복사/붙여넣기, 방향키 미세 이동, 핀치 줌, 단축키(`?`) |

## 구조

```
src/
  types.ts               데이터 모델 (Project / Layer / Frame / Cel)
  store/editor.ts        zustand 상태 + 실행 취소 히스토리 + 레이어/프레임 조작
  store/view.ts          캔버스 확대/이동
  lib/render.ts          프레임 합성 (레이어 투명도·합성 모드·이미지 변형)
  lib/audio.ts           오디오 디코딩, 파형, YIN 피치 검출, 재생
  lib/export.ts          MediaRecorder 동영상, GIF(gifenc), PNG
  lib/storage.ts         IndexedDB 저장, .ffanim 파일 형식
  components/            Home, Editor, Viewport, Timeline, LayerPanel …
```
