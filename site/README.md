# AMG 소개 · 다운로드 사이트

빌드 과정이 없는 정적 사이트예요. `index.html` 을 더블클릭하면 바로 열려요.

| 파일 | 내용 |
| --- | --- |
| `index.html` | 모든 문구 (소개, 사용법, 다른 점, 다운로드, 자주 묻는 질문) |
| `style.css` | 디자인 |
| `main.js` | 데모 애니메이션 재생, 내 컴퓨터에 맞는 다운로드 버튼 강조, 최신 버전 표시 |
| `assets/` | 앱 화면 사진, 아이콘, 데모 애니메이션(`demo-sheet.png`) |

다운로드 버튼은 GitHub Releases 의 최신 설치 파일을 가리켜요:
`https://github.com/crazyjiwoong/animating/releases/latest/download/AMG-Setup-Windows.exe`
